# Nemotron reasoning sprint — review evidence

Base: PR #49, `79929061570d0aa3c7e5e524f87dbbfbad6e7e51`. This change leaves PHIS Discovery, the synthetic generator, held-out seed, 16 frozen tests, thresholds, and scientific response values unchanged.

## Contracts

PLAN remains the strict two-key `{"family":"energy|sleep|none","tool":"discovery|trend|coverage|abstain"}` selection. The old CRITIQUE was only `{"decision":"accept|replan_coverage|abstain"}`; it could not explain the real PR #43 model abstention after 170/180 observed days and a passing PHIS coverage gate.

CRITIQUE is now exactly six keys: `schema="phis-critique.v2"`, `decision=accept|verify|abstain`, an allowlisted `reason_code`, up to three existing `evidence_signal_ids`, `requested_check=none|coverage`, and an English `explanation` of at most 220 characters. Duplicate keys, extra fields, non-JSON, fabricated IDs, unsupported checks, weak or negative-control promotion, and inconsistent decision/reason/check pairs are rejected. The explanation remains model metadata in World Model; the UI statement is assembled from validated PHIS facts and cited signals. If PHIS has qualified candidates, `insufficient_evidence` cannot falsely claim its scientific gates failed. A model may still abstain with `review_uncertain` and cited qualified IDs.

The model receives `phis-critic-evidence.v2`: dataset and canonical digest; actual 180-day coverage; all six precomputed 30-day windows and first-to-last descriptive difference; up to three qualified signals, one unstable signal and one negative control; exposure, outcome, effect, lag, N, q, temporal/robustness flags and a bounded sample of source IDs; the persisted scientific/tool event IDs and plan hashes; uncertainty; and the original adjacent 28-day coverage only as secondary context. The packet rejects inconsistent chronology, coverage, digest, source lineage, signal classification, and scientific event references before inference. No raw row values go to the model.

One optional deterministic coverage check recomputes the existing PHIS comparison gate. Signal and trend checks were excluded from the action allowlist because their narrow implementation only repeated packet validation. The coverage check output is hashed and persisted as a separate World Model tool event, then supplied to one final critique. A second verification request fails closed. The new append-only `agent_review_180d_v2` event records validated reason, citations, provider status/response ID, check event, original evidence references, digest and parent run. Existing v3/v4 event schemas stay readable.

## UI contract

The default local v3 route and the v4 route both begin with the complete fictional 180-day series, 170/180 Energy or 169/180 Sleep observed days, and six real 30-day descriptive intervals. PHIS-qualified associations remain distinct from Nemotron review. The model review appears once near the findings, with its cited IDs and reasoning in an expandable disclosure. The two adjacent 28-day periods remain under collapsed **Recent changes**. If model review abstains, the response blocks user-facing association cards but retains the original PHIS package under `scientific_audit` for the Evidence drawer, explicitly labeled as unendorsed by the model.

### One authentic NVIDIA local-source browser run

The owner-held DPAPI key was decrypted only in memory under the same Windows user, passed as `NVIDIA_API_KEY` solely to one hidden API child, then the child was stopped and the temporary launcher removed. The browser investigation used `SYNTHETIC_LOCAL_ONLY`, not Zetaris. World Model run `SYN-RUN-433a8b955b72` records a genuine NVIDIA plan response `chatcmpl-29cafb7b-5187-47bf-a6d2-5445e442eafd` and critique response `chatcmpl-3f7a7bc9-4f03-4d94-a86e-143267e8a6ed`. PHIS Discovery independently returned **PASS**, 170/180 Energy observations, 3 qualified candidates, 2 unstable candidates, 11 weak candidates, and canonical digest `fbc8653d5f0d8aeb84c65d06607d7821fbf1c3195088c6d023f17ae2c32a7cea`; scientific event `8f0afbd0d5187ca5c10be5428e3f75f7e37a146c98f1aef885d7c7317da659c1`. The model chose **abstain / insufficient_evidence** with no citations, while its wording described the qualified candidates as merely exploratory. PHIS correctly did not publish a model-endorsed finding. This was a genuine, unforced model decision, **not** a positive hosted acceptance and **not** proof of inadequate coverage.

The run exposed a semantic contract defect: a schema-valid abstention could contradict PHIS classification. After that single hosted run, the validator was tightened to reject `insufficient_evidence` when PHIS has qualified candidates, while allowing a model to abstain with `review_uncertain` and cited qualified IDs. The UI now derives review language from validated reason codes and keeps the full observed history visible as PHIS output when the model abstains. **No second hosted attempt was made. The final commit therefore has simulated and local Chrome proof, but no hosted-model proof on that exact SHA.** Treat the sprint as **NO-GO for submission freeze** until the founder reviews this limitation; retain PR #49 as the stable candidate.
