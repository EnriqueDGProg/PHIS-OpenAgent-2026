- [ ] Run the accepted demo mode using the public README. For LIVE, confirm an authenticated Zetaris query and six actual pages; for LOCAL, keep `SYNTHETIC_LOCAL_ONLY` visibly labelled. Do not substitute one for the other.
- [ ] Record one genuine energy question, open source/limits and tool trace, then a genuine World Model follow-up that selects sleep. Capture parent and follow-up run/event IDs. Record a scope-abstention input. Do not fabricate a replan or make two different runs appear continuous.
- [ ] For NVIDIA, show only the sanitized PR #35 receipt as a **separate local synthetic run** unless the final SHA has its own combined receipt. Never display the NVIDIA Build page, API key, `.env`, DPAPI file, provider console or raw prompt.
- [ ] Follow the [180-second storyboard](DEMO_SCRIPT_AND_STORYBOARD.md). Capture 1080p 16:9 with legible UI; pause on provenance, uncertainty and labels. Use real narration and compress only idle loading time.
- [ ] Play exported MP4 all the way through with sound; verify exactly <=4:00, no secrets/private data, no mismatched status badges, no clipped text. Test the video link in an anonymous browser.

## HackOS handoff

- [ ] Director and founder review the [deck](deck/PHIS_Open_Agent_2026_Track02_Review.pptx) visually and verify each screenshot's earlier SHA label. If later final-SHA captures exist, replace earlier ones and update notes/ledger.
- [ ] Review the [Description](HACKOS_FORM_DRAFT.md): Track 02, explicit pre-existing five-file disclosure, NEW work and sponsor boundaries. Check 150–2000 character live limit before paste.
- [ ] Ensure public default branch has the reviewed code, README, MIT/Apache notices and deck. Test GitHub solution, deck and video links in a signed-out browser. Draft PR branches alone are not a judge-ready release.
- [ ] Confirm the account's team/solo roster before first save. Upload or link real video and deck. Founder alone chooses Submit; keep the HackOS receipt and timestamp.
